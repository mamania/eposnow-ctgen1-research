# Contributing

Please classify findings as:

- **Confirmed** — directly observed on CTGEN1/T2s hardware or verified from a dump.
- **External reference** — documented elsewhere; include the source.
- **Hypothesis** — plausible but unproven on CTGEN1.

For dumps/loaders include:

- exact device/model;
- firmware/build;
- provenance;
- file size;
- SHA-256;
- whether the source device was known-good.

Redact personal data, account data and serials unless technically necessary.
